# ART VISION | Interactive AI Diploma Presentation

A Streamlit wrapper around the interactive HTML proposal.

## Deployment on Streamlit Community Cloud

1. Open https://share.streamlit.io and sign in with your GitHub account.
2. Choose **Create app** > **Yup, I have an app**.
3. Repository: `rewanebrahembadr-cmyk/https-claude.ai-artifact-RWYfQqGnGgGqq8Wz1Tfiy5` | Branch: `main` | Main file path: `app.py`.
4. Choose the app URL and click **Deploy**.
5. Open the resulting public link on desktop and mobile before sharing it with the client.

## Local run

```bash
pip install -r requirements.txt
streamlit run app.py
```

**Note:** This is the training curriculum presentation, not a real e-commerce store. The wall-art configurator and any prices are demonstrations, not validated company prices. Do not commit API keys or private customer data.
